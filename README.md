# Scooter Animation

This app shows a demo of the dashboard screen for an EV Scooter. This app has some interactive elements as well.
- Displays the speed of the vehicle with the starting animation
- Clicking on the speed will again play the start animation
- You can toggle between different riding modes like Economy, Reverse, etc using the left/right icons below

About the app's tech stack:
- Developed using Kotlin
- MVVM Architecture
- Jetpack Compose for the UI
- Manual Dependency Injection
